## About us

**GLSYS Kft.** is an IT services company focusing on **reliable operations**, **automation**, and **pragmatic infrastructure solutions** for small and medium-sized businesses.

We support our customers hands-on — from classic system administration to modern cloud and DevOps-oriented workflows — with a strong emphasis on stability, transparency, and long-term maintainability.

Our core areas include:

- Linux server operations and maintenance
- Hosting, domain, and web services
- Databases and troubleshooting (websites, CRM systems, on-prem environments)
- Automation and Infrastructure as Code (IaC)
- CI/CD pipelines and configuration management
- Monitoring, performance optimization, and cost awareness
- Security basics, hardening, and clean operational processes

Our philosophy: **keep systems simple, stable, and understandable** — no unnecessary complexity.
